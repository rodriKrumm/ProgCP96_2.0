# Editor Ladder CLP

Editor gráfico para programação Ladder de CLPs desenvolvido em C# Windows Forms.

## Funcionalidades

- Inserção de contatos
- Inserção de bobinas
- Edição gráfica
- Representação visual do programa Ladder
- Salvamento de projetos

## Tecnologias

- C#
- Windows Forms
- .NET Framework
